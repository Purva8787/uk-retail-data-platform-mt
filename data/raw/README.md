# Raw Source Data

This directory stores the original source datasets

## Required files

Place the following files in this directory:

- orders.csv
- order_items.csv
- customers.json
- products.csv
- reviews.json
- events.json
- bank_holidays.csv
- postcodes.csv
- regions.csv

## Important

Raw source datasets are excluded from Git using `.gitignore`.

They must be placed in this directory locally before running the ingestion and data-processing scripts.
